# Andej Karpathy's Youtube Course

This Repo contains my own notebooks in which I attempt to solve the exercises given in the description of each of Andrej Karpathy's Youtube lectures on Neural Networks (Link to the playlist: https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ). 

This initially involves implementing my own version of:
- *Micrograd* - to help build an understanding of backpropagation
- *Makemore* - to learn how to build simple neural networks, introduce frequently used pytorch functions, and familiarise myself with concepts such as regularisation, softmax functions, and gradient descent.

But will go into concepts such as: 
- Multi-Layer Perceptron (MLP)
- Bag of Words
- Transformers
- small LLM's

## Repository Details

This repo is structured such that files pertaining to each video in the Youtube series are stored in their own directory. There is often repeated code that builds upon previous work, but I have left this included to show the process of iterative improvements and because manual calculations are educational, even if redundant with proper use of pytorch functionality.
